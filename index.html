Empecemos: cuéntame de tu equipo
Llena todo una sola vez y te armo un informe técnico con palabras sencillas: estado de tu PC, qué sistema operativo te conviene, qué mejorar y qué comandos usar.




















Paso 1: averigua tus datos. Abre CMD (Win+R → cmd → Enter), pega esto y compara con las listas de arriba. El número después del guion indica la generación (i5-8250U → generación 8). En la RAM, 8589934592 = 8 GB.
:: Procesador
wmic cpu get name
:: Memoria RAM (en bytes)
wmic memorychip get capacity
:: Disco (MediaType: SSD o HDD)
powershell -command "Get-PhysicalDisk | Select FriendlyName,MediaType"
:: Windows actual
ver
:: Si wmic no existe en tu Windows:
powershell -command "Get-CimInstance Win32_Processor | Select Name"
